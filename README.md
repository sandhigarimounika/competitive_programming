# Competitive Programming Practice

A collection of Python solutions and notes for coding exercises, including linked lists, binary trees, stacks, strings, and other LeetCode-style problems. Files named `leetcode.<number>.py` correspond to problem numbers; other filenames describe their exercises.

Browse the files to study individual approaches. Many solutions are written for an online judge and expect the judge to provide types such as `ListNode`, `TreeNode`, or `Optional`; they are not necessarily standalone scripts. There is no shared application or test runner in this repository.
